Purpose of AI Use: AI was used to draft and implement the feature
Chat Link or Prompt/Response: Link to the conversation or the full prompt and AI response.

    As a job seeker, I want to upload, replace, download, and delete my resumes so that I can keep my documents current and reuse them across job applications.

    ### Acceptance Criteria

    Users can upload PDF and DOCX files.
    Unsupported file types are rejected with a clear message.
    Files exceeding the 5 MB limit are rejected.
    File contents are validated, not only the filename extension.
    Users can see a list of their uploaded resumes.
    Each resume displays its filename, size, and last-updated date.
    Users can download an uploaded resume.
    Users can replace an existing resume while retaining its record.
    Users can delete a resume.
    Users cannot access another user’s resumes.
    Uploaded files and metadata persist after restarting the server.
    Failed operations do not leave orphaned files or metadata.

    ### API Design

    Method    Endpoint                     Purpose
    ━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
    GET       /api/resumes                 List the current user’s resumes
    ────────  ───────────────────────────  ─────────────────────────────────
    POST      /api/resumes                 Upload a resume
    ────────  ───────────────────────────  ─────────────────────────────────
    GET       /api/resumes/:id/download    Download a resume
    ────────  ───────────────────────────  ─────────────────────────────────
    PUT       /api/resumes/:id             Replace a resume
    ────────  ───────────────────────────  ─────────────────────────────────
    DELETE    /api/resumes/:id             Delete a resume

    Uploads use multipart/form-data with a field named resume.

    ### Metadata

    Each resume record should contain:

    Resume ID
    Owner/user ID
    Original filename
    Generated storage filename
    MIME type
    File size
    Creation date
    Last-updated date
