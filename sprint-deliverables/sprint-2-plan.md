# Sprint 2 Plan

## Overview

This document outlines the plan for Sprint 2 of the project. It includes the objectives, and deliverables for the sprint, as well as the responsibilities of each team member.

## Objectives

The goal of sprint 2 is to continue on the work started in sprint 1 by adding new features and improving test coverage.

The specific new features to be added in this sprint include:

1. User Profile & Management:
   - Allow job seekers to create and edit their professional profile.
   - Allow users to upload, replace, and manage resumes.
   - Display uploaded resumes and profile information.
2. Job Search and Job Listing Interface
   - Display available job opportunities.
   - Provide search and filtering capabilities based on keywords, location, or category.
   - Allow users to view detailed job descriptions.
3. Job Application Submission and Tracking
   - Allow job seekers to apply for a job posting.
   - Track application status (Applied, Under Review, Interview, Offered, Rejected).
   - Provide confirmation of successful application submission.
4. Recruiter Dashboard and Posting Management (start in Sprint 2, complete in Sprint 3)
   - Allow recruiters to create and manage job postings.
   - Display applications received for a posting.

## Deliverables

The deliverables for Sprint 2 include:

- This document (Sprint 2 Plan)
- User stories for the new features (with tasks and acceptance criteria)
- At least 2 acceptance tests for each user story from Sprint 1 and Sprint 2
- Sprint 2 feature implementation
- AI Usage Logs
- Project board and backlog
- A CI pipeline that automatically runs tests
- Meeting minutes
- Contribution logs (per team member)
- One page summary report (per team member) of the work completed in Sprint 2

## Work Breakdown

The work for Sprint 2 will be broken down as follows:

Each team member will be assigned a specific feature (see above) to implement. They will be responsible for writing the code, creating tests, and ensuring that their feature meets the acceptance criteria.
